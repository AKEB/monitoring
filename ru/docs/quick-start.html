Быстрый старт

От запущенного сервера до первой зелёной проверки за несколько минут.

  1. Откройте UI и войдите как admin.
  2. Создайте воркер Workers → Create. Скопируйте WORKER_KEY_HASH.
  3. Запустите воркер на хосте с доступом к серверу:
    docker run -d \
  --name monitoring-worker \
  -e SERVER_HOST=https://your-monitoring-server.com \
  -e WORKER_KEY_HASH=your_unique_worker_key_here \
  akeb/monitoring-worker-go:latest
  4. Создайте монитор — Monitors → Create → HTTPS, URL, интервал, назначьте воркер.
  5. Добавьте канал уведомлений (по желанию) и привяжите к монитору.

Первые результаты обычно за минуту. Дальше: интерфейс или агенты.
