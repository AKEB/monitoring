Переменные окружения

Полный справочник для сервера, Go-воркера и агента. Значения по умолчанию — из кода и .env.example.

Где задаватьСервер: Compose environment / .env. Воркер и агент: env процесса или файл .env рядом с бинарником. См. также Воркеры и Агенты.
