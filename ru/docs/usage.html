Возможности

Обзор Дашборд Мониторы Воркеры Агенты хостов Docker-хосты Уведомления Обслуживание RBAC и аудит Аутентификация SSL и события API и MCP

Интерфейс

Повседневная работа с дашбордом и админкой.

Дашборд

  • Дерево папок и мониторов с правами на чтение; сворачивание запоминается
  • Бейджи статуса и availability за 24 часа
  • Фильтр Success / Error / Warning / Unknown / Maintenance; поиск по имени
  • Фоновое обновление по WebSocket
  • На мобильном: переключение List / Data

Карточка монитора

  • Uptime-полоса за 24 часа
  • Графики времени ответа или метрик (30м–24ч)
  • Таблица событий
  • Тема следует системной light/dark

Админка

По правам: Workers, Monitors, Notify, Signatures, Dockers, Servers, Maintenances, пользователи/группы/права/логи, API-токены в Settings.
