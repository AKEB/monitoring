API и MCP

Автоматизация через токены, REST, Swagger и MCP.

API-токены

Settings → API: токены mnt_… как Authorization: Bearer или X-Api-Token. Права = владелец токена.

User Status API

GET /api/v1/status/ — только мониторы с api_enabled. Статусы, availability, SSL, воркеры, maintenance.

Management API v2

CRUD сущностей, права, логи. Swagger: /api/docs/.

MCP

POST /mcp/ — инструменты как у v2 плюс api_docs.

  • External callback
