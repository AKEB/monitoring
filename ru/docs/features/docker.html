Docker-хосты

Регистрация endpoints Docker Engine API, чтобы воркеры проверяли контейнеры по TLS.

Настройка

  • Адрес и порт
  • TLS CA / client cert / key (PEM только на запись)
  • Опционально tls_server_name, если IP не совпадает с DNS в сертификате
  • Какие воркеры опрашивают хост
  • Включение/выключение и ACL

Мониторы типа Docker выбирают контейнер из AJAX-списка.
