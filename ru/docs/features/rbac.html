RBAC и аудит

Детальные права на объекты, наследование от папок и журнал аудита.

Субъекты

monitor, worker, notify, maintenance, docker, signature, server, а также user/group.

Уровни

  • Read / Write / Delete
  • ACCESS_* для управления ACL
  • create_* на типы сущностей
  • Секреты: ключ воркера, notify, agent_key_hash

Пользователи и группы

CRUD, членство в группах, UI прав, impersonate, audit logs.
