Status pages

Публичная HTML-страница статуса по адресу /status/{slug}/ без доступа к админке и без включения Status API для каждого монитора.

Membership ≠ api_enabled Добавление монитора на status page влияет только на публичный HTML. В GET /api/v1/status/ монитор попадает только при флаге api_enabled.

Что видит посетитель

  • Общий статус: всё в порядке / частичный сбой / серьёзный сбой / обслуживание
  • Список мониторов с полосками heartbeat за 24ч и uptime
  • Опубликованные инциденты (заголовок, текст, severity, время)
  • Опциональный custom header HTML и footer
  • Переключатель EN / RU (?lang= или cookie)

Какие мониторы показываются

Только листья: не папка, включён (status=1), все родительские папки включены. Пустые папки и выключенные ветки скрыты.

Админка

  1. Меню Status pages (по ACL).
  2. Создайте страницу: slug, title, description, theme, published.
  3. Привяжите мониторы, которые вам доступны на чтение.
  4. Добавляйте / редактируйте / удаляйте инциденты в редакторе страницы.
  5. Отдайте ссылку https://your-host/status/{slug}/ после публикации.

API и MCP
