Агенты хостов

Бинарник monitoring-agent пушит телеметрию хоста на сервер примерно каждые 30 секунд.

Что отдаёт

  • Идентичность хоста, uptime, виртуализация
  • CPU, память/swap, диски, сеть
  • Docker-контейнеры при доступном сокете
  • Гости Proxmox VE при наличии /etc/pve
  • События auth, топ процессов
  • Слушающие TCP/UDP порты (IP, порт, процесс, сервис)

UI сервера

Admin → Servers → Create даёт AGENT_KEY_HASH. На карточке — графики, слушающие порты, Proxmox, auth, ротация ключа, целевая версия.

Установка в Docker

docker run -d --name monitoring-agent --restart unless-stopped \
  --net host \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  -e SERVER_HOST=https://monitoring.example.com/ \
  -e AGENT_KEY_HASH=... \
  akeb/monitoring-agent:latest

Без Docker — скачать бинарник с GitHub

Go на хосте не нужен. Файлы: monitoring-agent-linux-amd64 / linux-arm64 (+ .sha256) в релизах AKEB/monitoring-agent. Подходит для Proxmox, Debian, Raspberry Pi, LXC.

# Pick the latest tag on https://github.com/AKEB/monitoring-agent/releases
VER=v1.3.0
ARCH=amd64   # or arm64

sudo mkdir -p /opt/monitoring-agent
sudo curl -fsSL -o /opt/monitoring-agent/monitoring-agent \
  "https://github.com/AKEB/monitoring-agent/releases/download/${VER}/monitoring-agent-linux-${ARCH}"
sudo chmod 755 /opt/monitoring-agent/monitoring-agent

# Optional checksum check:
# curl -fsSL -o /tmp/monitoring-agent.sha256 \
#   "https://github.com/AKEB/monitoring-agent/releases/download/${VER}/monitoring-agent-linux-${ARCH}.sha256"
# echo "$(cat /tmp/monitoring-agent.sha256)  /opt/monitoring-agent/monitoring-agent" | sha256sum -c -

sudo tee /opt/monitoring-agent/.env >/dev/null <<'EOF'
TZ=Europe/Moscow
SERVER_HOST=https://monitoring.example.com/
AGENT_KEY_HASH=paste_agent_key_here
REPORT_INTERVAL_SEC=30
AUTO_UPDATE=true
EOF

sudo tee /etc/systemd/system/monitoring-agent.service >/dev/null <<'EOF'
[Unit]
Description=Monitoring host agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/monitoring-agent
ExecStart=/opt/monitoring-agent/monitoring-agent
Restart=always
RestartSec=5
EnvironmentFile=-/opt/monitoring-agent/.env

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now monitoring-agent
journalctl -u monitoring-agent -f

Полный список переменных: Окружение → Агент.

Опционально: сборка из исходников

Только для кастомной сборки — на серверах обычно не нужна.

# Only if you need a custom build — prefer GitHub Releases on servers.
go build -buildvcs=false -o monitoring-agent ./cmd/agent/
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -o monitoring-agent-linux-amd64 ./cmd/agent/
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -buildvcs=false -o monitoring-agent-linux-arm64 ./cmd/agent/

Производные мониторы

Типы Server-* привязываются к зарегистрированному серверу: offline/CPU/RAM/диск/контейнер/сеть/слушающий порт.
