Monitoring

Распределённый мониторинг доступности и хостов: сервер, удалённые воркеры и агенты. HTTP, TCP, Ping, Docker, exporter и метрики серверов из разных регионов — с умными алертами без спама.

Что умеет система

Откройте карточку — подробное описание с настройкой и скриншотами.

Ядро

Типы проверок

HTTPS, HTTP JSON, TCP, Ping, Docker, External, node-exporter и метрики агента.

Масштаб

Распределённые воркеры

Лёгкие Go-воркеры в любых сетях и регионах для объективной доступности.

Хосты

Агенты хостов

CPU, RAM, диски, сеть, Docker, гости Proxmox и события auth с каждого сервера.

Алерты

Умные уведомления

Telegram, Mattermost, Gotify, MAX, webhook — с действиями mute / take / resolve.

Доступ

RBAC и тенанты

Пользователи, группы, ACL с наследованием от папок, секреты и журнал аудита.

Интеграции

API и MCP

Status API, Management API v2, Swagger и MCP-инструменты для автоматизации.

Архитектура

Три роли, одна панель управления. Подробнее на странице архитектуры.

Сервер

akeb/monitoring

Веб-UI, MySQL, API, алерты, ACL.

Воркер

akeb/monitoring-worker-go

Выполняет проверки из удалённых точек.

Агент

akeb/monitoring-agent

Отправляет метрики хоста каждые ~30 с.
