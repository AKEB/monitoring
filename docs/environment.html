Environment variables

Complete reference for the Server container, Go Worker and Host Agent. Defaults match the current code / .env.example files.

Where to set themServer: Compose environment / .env. Worker and Agent: process env or a .env file next to the binary (or in the working directory). See also Workers and Agents for binary installs.
