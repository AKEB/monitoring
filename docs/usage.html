Using the UI

Day-to-day operations on the dashboard and admin screens.

Dashboard

  • Folder tree of monitors you can read; collapse state is remembered
  • Status badges and 24h availability %
  • Filter by Success / Error / Warning / Unknown / Maintenance; search by title
  • WebSocket background refresh for the list and the selected monitor
  • On mobile: bottom nav toggles List vs Data panes

Monitor detail

  • Uptime bar (24h segments)
  • Response-time or metric charts (30m–24h), per worker when applicable
  • Events table (status transitions)
  • Theme follows system light/dark

Admin areas

Permission-gated menus: Workers, Monitors, Notify, Signatures, Dockers, Servers, Maintenances, Users/Groups/Permissions/Logs, API tokens under Settings.
