SSL & events

SSL expiry

  • HTTPS / HTTP JSON can verify certificates and hostnames
  • Workers report cert_expire; cron notifies on day thresholds 15/7/6/5/4/3/2/1
  • Once per day per monitor; notify channels + in-app subscribers; signatures appended
  • Exposed in Status API as ssl_expire_time / ssl_expire_at

Events

  • Status transitions stored in monitoring_events with hash deduplication
  • Shown on the home feed and per-monitor (~2 day window)
  • Raw logs aggregated; detail retention about 24 hours
