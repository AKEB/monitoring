Maintenance

Schedule planned windows so checks show Maintenance instead of noisy failures.

  • Title, start_time / finish_time (finish ≥ start)
  • Attach any monitors you can read; folders inherit to children
  • Status appears on the dashboard and in the Status API
  • ACL: access + create_maintenance

UI: /maintenances/ (user-facing, not only admin).
