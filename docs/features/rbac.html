RBAC & audit

Fine-grained access control for every major object, with folder inheritance and a full audit trail.

Subjects

monitor, worker, notify, maintenance, docker, signature, server, plus Framework user/group.

Levels

  • Read / Write / Delete
  • ACCESS_READ / ACCESS_WRITE / ACCESS_CHANGE for managing ACL itself
  • create_* permissions per entity type
  • Secrets: worker key, notify secrets, server agent_key_hash

Users & groups

Admin CRUD, group membership, per-object permissions UI at /admin/permissions/{subject}/{id}/, impersonate, audit logs.
