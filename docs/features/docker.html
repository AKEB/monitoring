Docker hosts

Register Docker Engine API endpoints so workers can check container state over TLS.

Configuration

  • Host address and port
  • TLS CA / client cert / key (PEM write-only; API only exposes tls_present)
  • Optional tls_server_name when the IP does not match the certificate DNS
  • Link which workers may poll the host
  • Enable/disable + ACL

Docker-type monitors pick a container name from AJAX lists. Interval/timeout can follow the Docker host settings.
