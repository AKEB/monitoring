API & MCP

Automate Monitoring with personal tokens, REST, Swagger and an MCP endpoint.

API tokens

Settings → API: create/revoke tokens (mnt_…). Send as Authorization: Bearer or X-Api-Token. Rights equal the token owner; secrets redacted without permission.

User Status API

GET /api/v1/status/ — opt-in monitors only (api_enabled). Returns up/down/maintenance/unknown, availability windows, SSL expiry, workers, maintenances. Cached ~20s with rate limits.

Management API v2

REST CRUD for monitors, notify, signatures, workers, maintenances, dockers, servers; users/groups read-only; logs by date; permissions GET/PUT. Interactive docs: /api/docs/ (OpenAPI /api/docs/openapi.json).

MCP

POST /mcp/ JSON-RPC; tools mirror v2 plus api_docs. Suitable for Cursor-style remote MCP configs.

Other endpoints

  • External callback: public hash URLs for External monitors; optional Log header or ?log= / ?message= (see Monitors → Log)
  • Agent report: POST /api/agent/report/
  • Alert-action callbacks for messenger buttons

Deep protocol notes: server docs (WORKER_API.md, USER_API.md, MANAGEMENT_API.md, AGENT_API.md).
