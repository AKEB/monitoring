Authentication

Sign-in options are controlled by environment variables on the server.

MethodEnv / notes
Email + passwordAPP_SIGNIN_ACTIVE; signup via APP_SIGNUP_ACTIVE
Forgot passwordSMTP settings (SMTP_*)
OpenID ConnectOPENIDCONNECT_* provider, client, scopes, optional auto-register
Generic OAuthOAUTH_* auth/token/userinfo endpoints
2FAFramework settings (disable path in profile)

UI uses session cookies. Management/Status APIs use personal Bearer tokens and ignore cookies.
